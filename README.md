# PopcornEcho - A Movie Explorer Application

This application is built using React. Here a user will be able to browse movies, search for specific titles, and view detailed information in an interactive modal.

## 🌐 Application URL

Currently, the application is live on: [PopcornEcho](https://movie-explorer-app-flame.vercel.app)

## 🛠️ Technology Stack

- **Core:** JavaScript, React
- **Styling:** CSS, Tailwind CSS _(Optional but recommended)_
- **Data:** Free Movie Database API _(e.g., OMDB, TMDB, TVMaze)_
- **TVMaze Doc:** [API](https://www.tvmaze.com/api)
